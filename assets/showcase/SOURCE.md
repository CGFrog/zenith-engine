# Renderer showcase provenance

Generated by `tools/showcase/build_showcase.py` (Blender) followed by
`tools/showcase/compress_textures.py`; see `tools/showcase/README.md` to
rebuild. The source libraries are the user's local asset collections and are
not copied into the repository; only these converted runtime files are.

## Textures (`textures/`)

Converted from the user-supplied texture library (Textures.com sets) at 1K,
following the conventions in `assets/textures/SOURCE.md`: normal maps have the
green channel flipped from DirectX to glTF/OpenGL convention, and roughness
(plus metallic where provided) is packed into `*_orm.png` (R = 1, G = roughness,
B = metallic). Colour and normal maps are stored as JPEG, packed and alpha maps
as PNG.

| Prefix | Source set |
| --- | --- |
| `concrete_` | `Rock/Concrete2/T_Concrete_WW2_2x2_*` (roughness scaled by 0.45 for a polished floor) |
| `brick_` | `Industrial/Bricks1/T_Wall_BrickSloppy_2.5x2.5_*` |
| `stone_` | `Rock/Stone2/T_Stone_BaseSurface3_1x1_*` |
| `galvanized_` | `Metal/Galvanized Metal 1/T_Metal_Galvanized_*` (metallic 1) |
| `aluminium_` | `Metal/Aluminium 1/T_OldAluminium_Worn_*` (metallic 1) |
| `metalsheet_` | `Metal/Metal Sheet 1/T_MetalSheet_Aged_*` (metallic map) |
| `rust_` | `Metal/Rust 1/T_Rust_Heavy_MediumRust_*` (metallic 0) |
| `fern_` | `Plants/Fern1 (House)/T_Plant_HouseFern_*` (alpha map in base colour alpha) |
| `grass_` | `Plants/Grass1/T_Grass13_*` (alpha map in base colour alpha) |
| `graniterock_` | Photoscan `Granite Pond Rock 2` texture atlas, resized to 2K |

## Geometry (`showcase.gltf`, `showcase.bin`)

Built procedurally in Blender except `GraniteRock`, which is the user's
Meshroom photoscan `Granite Pond Rock 2`: decimated to about 60k triangles,
laid flat, cropped to the boulder and its immediate surroundings, and scaled
to 1.8 m.

## Reflection probe environments (`probe_cool.hdr`, `probe_warm.hdr`)

Stylized interiors generated by `tools/showcase/build_probe_environments.py`
(pure Python) as stand-ins for baked captures of the room's west and east
halves.

## Environment (`sky.hdr`)

Blender's bundled `courtyard.exr` studio-light world HDRI, converted to
Radiance HDR. Blender distributes these HDRIs from Poly Haven under CC0.
