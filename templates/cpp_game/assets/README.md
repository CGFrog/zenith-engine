# {{PROJECT_NAME}} assets

Runtime content for {{PROJECT_NAME}}: glTF models, textures, audio, and
fonts. Scenes and components refer to an asset by its path below this folder
(and by the GUID in its `.meta` file, which the editor writes), so moving
assets in the editor's Asset Browser keeps scenes working.

`primitives/cube.gltf` is the starter model the ground and cube in
`scenes/main.zenith-scene` use.
