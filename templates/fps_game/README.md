# {{PROJECT_NAME}}

A Zenith first-person game project, generated by the Zenith editor's Project
Hub from the First-Person Shooter template: walk the course, shoot the five
targets, and reach the exit.

| Path | What it holds |
| --- | --- |
| `{{PROJECT_IDENTIFIER}}.zenith-project` | The project file the editor opens: its folders, startup scene, render settings, game module, input actions, and tags. |
| `scenes/main.zenith-scene` | The course: floor and walls, the player (a character with a camera child carrying the Hitscan Weapon), five tagged targets, and the exit sensor. |
| `assets/` | The cube model and `prefabs/impact.prefab`, the spark burst a shot leaves. |
| `input_actions.json` | The input actions and bindings: Move, Look, Jump, Sprint, Fire, Pause, and the menu actions. Edit them in **Edit > Project Settings > Input Actions**. |
| `src/` | The game module. `FpsGame.*` holds the round's state, its events, the score system, and the HUD and menus; `HitscanWeapon.*`, `Target.*`, and `GoalZone.*` are behaviours. |
| `CMakeLists.txt`, `CMakePresets.json` | Build the module against the Zenith engine at `ZENITH_ROOT`. |
| `modules/` | Where each build copies the module for the editor. Generated; not versioned. |

## Build and play

1. Open the project in the editor and press **Ctrl B**. The editor loads the
   module when the build finishes and reloads it after every later build.
   Until then the targets' and weapon's behaviours are kept as data.
2. Press **F5**. Click the game view to capture the mouse, then walk with WASD,
   look with the mouse, and shoot with the left button. **Escape** releases the
   mouse and pauses; Settings changes the look sensitivity.
3. Outside the editor, `zenith --project {{PROJECT_IDENTIFIER}}.zenith-project`
   plays the same scene with the same module.

The `zenith` preset (`cmake --preset zenith`, `cmake --build --preset zenith`)
builds the `{{BUILD_CONFIG}}` configuration with the engine's compiler, against

    {{ZENITH_ROOT}}

## Change the game

- **Module > New Behaviour**, **New Component**, and **New System** write a
  new type into `src/` and wire it in above the `zenith:` marker lines in
  `src/CMakeLists.txt` and `src/GameModule.cpp`; keep those lines.
- A behaviour's **Edit Script** button in the inspector opens its source.
- `docs/tutorials/fps-game/` in the Zenith source tree walks through this
  project.
